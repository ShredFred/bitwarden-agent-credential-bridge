# Trademark and naming

This is a community research project. It is **not** affiliated with, endorsed
by, or supported by Bitwarden, Inc. or any Bitwarden trademark owner.

## What you may do

- Refer to this repository as **Agent Credential Bridge**.
- State, accurately, that it can resolve secrets from an operator-owned
  Bitwarden Secrets Manager machine account.
- Cite [Bitwarden Agent Access](https://github.com/bitwarden/agent-access) as
  an independent upstream protocol/SDK that inspired the *problem statement*
  (agents should not eat vaults), not as a dependency or compatibility claim.

## What you may not do

- Use Bitwarden logos, the Bitwarden shield, or Bitwarden trade dress.
- Imply certification, partnership, or that this is an official Bitwarden
  Agent Access implementation.
- Ship this software under a name that is confusingly similar to Bitwarden
  product names.
- Treat Apache-2.0 license alignment as permission to use Bitwarden marks.

The code is Apache-2.0. Names and marks are not. See
[Licensing](licensing.md).
